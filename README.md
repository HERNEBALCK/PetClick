# PetClick 1.5.3

一个离线的 Windows 拍键盘计数桌宠。现在默认宽 160、高 169，约为最初版本面积的四分之一。

[代码导读：从输入、动作到存档](docs/代码导读.md) · [项目清理记录](docs/清理记录.md)

GitHub 仓库保存源码、素材、文档和测试，不包含本机的 `release/`、`backups/`、`node_modules/` 或个人存档。从 GitHub 克隆后，请按下方“从源码运行”操作；需要生成便携程序时运行 `npm.cmd run dist`。

## 直接使用

双击 `release/PetClick-1.5.3-win-x64.exe`，不需要安装 Node.js，也不需要联网。Windows 10 / 11 x64 可用。

桌面快捷方式名为「Miku 桌宠」，使用可爱的 Miku 头像，指向 `release/win-unpacked/PetClick.exe`。保留项目目录和这个程序文件夹即可继续使用。需要重建快捷方式时运行 `scripts/create-desktop-shortcut.ps1`；新图标同时用于程序和托盘。

更新前先右键旧桌宠选择退出，再打开新版。两版使用同一个存档目录，累计次数会继续保留。旧版本的缩放设置不再影响新版大小。

- **鼠标点击小键盘或右侧计数牌**：累计次数加一，原图手臂落到相应键盘区域并下压。
- **在其他软件敲键盘**：对应键帽亮起、压下，角色左右手联动；不增加计数，也不抢输入焦点。
- 保留原图从肩部露肤到袖口的整条手臂，取消横向截断与整体平移。整臂绕固定肩膀抬起、落下，按键区域只影响小范围落点，不拉伸。静止和回位使用原图姿势，头发与脸部遮住肩部根部；手臂移开时才显示补绘的身体底图。小键盘保持上移，计数牌独立位于右侧。
- 键盘已旋转朝向 Miku，并带轻微桌面透视；使用旋转后键帽的真实屏幕坐标选择左右手与肩部角度，落点更靠近按键。手臂仍保持原图形状，边角键采用有限范围内的近似落点。
- 按住键时停在下压姿势，松开才回位；组合键中仍有同侧按键未松开时，手臂转向该键并继续保持。
- 键盘采用 104 键布局，包含左右修饰键、方向键、功能区和数字键盘。按住时键帽保持亮起，松开解除。
- 拖头部移动窗口。右键或托盘菜单提供显示、置顶、键盘联动开关、移回右下角及退出。
- 已移除“大小”和“打开存档目录”菜单项。

默认静音、置顶、开启键盘联动；不会开机自启。

待机时角色每 4.5 秒轻轻起伏一轮，160 像素窗口中的最大幅度约 3.84 像素，随机眨眼保留。空闲 4～8 秒后，原画口水会从嘴边逐渐拉长、变细，再断开滴落，约 2.2 秒完成并恢复原状。开始输入会取消水滴并暂停呼吸；所有键松开、手臂回位后恢复待机。身体与手臂同步移动，键盘和计数牌保持稳定。系统开启减少动态效果时停用呼吸和水滴。

本次原有 PNG 素材逐字节保持不变，水滴为 SVG 叠加效果。

## 输入与存档

键盘桥接程序仅在桌宠运行时接收物理按键编号及按下/松开状态，通过私有管道传给桌宠。不会将键盘转换成输入文字，不记录文本、按键历史或输入统计，也没有联网功能。退出桌宠、关闭键盘联动或锁屏时停止监听；正常解锁后按设置恢复。

计数仍然只累计鼠标点击，正常关机或退出重开都不会清零。固定目录是 `%APPDATA%\PetClick`，通常位于 `C:\Users\你的用户名\AppData\Roaming\PetClick`。

- `state.json`：累计次数、位置、置顶及键盘联动设置。
- `state.backup.json`：有效备份。
- `*.damaged-*`：保留下来的故障原文件。

正常保存完全静默，不显示“保存中”。只有写入失败才提示并重试。每次鼠标点击都会依序写入临时文件、同步磁盘、再替换正式文件，并维护备份。写入失败会保留内存次数并自动重试，界面显示提示。突然断电仍可能丢失尚未写入的最后几次。需要手动备份时，先退出桌宠，再复制整个目录。

## 从源码运行

本机开发环境：Node.js 24、Electron 43.8.3。使用 Windows 自带 .NET Framework C# 编译器构建很小的键盘桥接程序，用户运行便携版不需要自行编译。

```powershell
npm.cmd ci
npm.cmd start
```

`npm start` 会先编译原生桥接程序。首次下载依赖需要联网，桌宠日常运行完全离线。

```powershell
npm.cmd test
npm.cmd run check
node scripts/smoke.js
npm.cmd run dist
node scripts/package-smoke.js
```

- `src/main.js`：窗口、菜单、存档与输入桥接生命周期。
- `src/keyboard-input.js`、`native/KeyboardBridge.cs`：按键编号接收与释放，不存输入记录。
- `src/keyboard-layout.js`：104 键布局和物理扫描码映射。
- `src/arm-motion.js`：完整手臂绕肩部旋转，按区域轻微调整落点，连续抬起、下压和回位。
- `src/renderer.js`：点击、键帽高亮、手臂及眨眼。
- `src/store.js`：原有可靠存档与备份。

原图保留在 `assets/original.png`。显示的角色和完整手臂均来自 `assets/pet.png`，SVG 只负责整条手臂的边界与旋转，不绘制新手臂。`assets/pet-backing-v14.png` 是内置 imagegen 补绘的身体底图，仅在手臂移开时通过局部遮罩显示，不替换原画的脸、头发或手臂。静止时关闭底图，恢复原画身体。废弃素材已清理，历史快照保存在备份中。[素材与提示词](assets/GENERATION.md) · [验收记录](TESTING.md)。

键盘分区：T/Y、G/H、B/N 之间划分左右手；因键盘朝向 Miku，实体键盘左半区驱动画面右手，右半区驱动画面左手。空格交替分配，方向键和数字区归右半区。

主打字区（不含数字区）中心自动对齐 Miku 双肩中间，窗口尺寸改变时继续保持对齐。

1.5.3：统一双臂轮廓的边框宽度，补齐领带遮挡的袖套内侧小缺口；原画 PNG 保留，口水活动时只在原口水区域内显示补绘底图。
